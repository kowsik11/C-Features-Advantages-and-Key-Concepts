Virtual Function:
Definition: A function declared with the VIRTUAL keyword in a base class.
Implementation in Base Class: Can have a body (implementation).
Purpose: Allows a derived class to override the function but doesn’t enforce it.
Class Type: The base class can be used as it is.
Example:

Copy code
class Base { 
    virtual void show() { cout << "Base"; } 
};

class Derived : public Base {
public:
    void show() override { // Mandatory implementation in derived class
        cout << "Derived class show function" << endl;
    }
};

int main() {
    Base* ptr;       // Base class pointer
    Derived d;       // Derived class object
    ptr = &d;        // Pointer points to derived object
    ptr->show();     // Calls the derived class's show() function
    return 0;
}

function overriding:

when a derived class provides its own implementation of a function that is already defined in its base class. The function in the base class is marked as VIRTUAL, allowing runtime polymorphism.

#include <iostream>
using namespace std;

class Base {
public:
    virtual void display() { // Virtual function
        cout << "Display function in Base class" << endl;
    }
};

class Derived : public Base {
public:
    void display() override { // Overriding the function
        cout << "Display function in Derived class" << endl;
    }
};

int main() {
    Base* basePtr;         // Base class pointer
    Derived derivedObj;    // Derived class object

    basePtr = &derivedObj; // Base pointer points to derived object
    basePtr->display();    // Calls the overridden function in Derived class

    return 0;
}

output: Display function in Derived class

Internal Implementation of a HashMap:

A HashMap is a data structure that stores key-value pairs and allows for efficient retrieval, insertion,
and deletion based on keys. It is based on hashing, which uses a HASH FUNCTION to compute an index
(or hash code) where the value is stored. 

HashMaps, collision resolution is essential because multiple keys might hash to the same index.

Linear Probing, Quadratic Probing, Double Hashing

> Linear Probing
How It Works:
When a collision occurs, the algorithm checks the next sequential index (e.g., index+1, index+2, etc.) until an empty slot is found.

Quadratic Probing
How It Works:
Instead of checking the next sequential index, it checks indices at intervals determined by a quadratic function (e.g.index+1^2, index+2^2,, etc.).

Double hashing:  More complex, requires 2 hash functions

formula:= index + (i * h2(key))

Malloc and calloc are C library functions that perform dynamic memory allocation:

Malloc
Allocates a single block of uninitialized memory of a specified size. It takes one argument, the total memory size. The values in the allocated memory are random (garbage values).

Calloc
Allocates memory for an array of elements of a specific size, initializing all the bytes to zero. It takes two arguments, the number of elements and the size of each element.

Identical trees or not ?!

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node* left, * right;
};

bool areIdentical(Node* root1, Node* root2) {
    if (!root1 && !root2) return true;
    if (!root1 || !root2) return false;
    return (root1->data == root2->data) &&
           areIdentical(root1->left, root2->left) &&
           areIdentical(root1->right, root2->right);
}

int main() {
    // Example trees
    Node* root1 = new Node{1, nullptr, nullptr};
    Node* root2 = new Node{1, nullptr, nullptr};

    cout << "Are trees identical? " << (areIdentical(root1, root2) ? "Yes" : "No") << endl;
    return 0;
}

Loop detected in Linkedlist

bool detectLoop(Node* head) {
    if (head == nullptr) return false;

    Node* slow = head;
    Node* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;            // Move slow pointer by 1 step
        fast = fast->next->next;      // Move fast pointer by 2 steps

        if (slow == fast) {
            return true;  // Loop detected
        }
    }

    return false; // No loop
}



2nd largest element in an array

int findSecondLargest(int arr[], int n) {
    int first = INT_MIN, second = INT_MIN;

    for (int i = 0; i < n; i++) {
        if (arr[i] > first) {
            second = first;
            first = arr[i];
        } else if (arr[i] > second && arr[i] != first) {
            second = arr[i];
        }
    }

    return second;
}

2- Find the repeated elements from the array. (No STL Allowed)

#include <iostream>
using namespace std;

void findRepeatedElements(int arr[], int n) {
    const int MAX = 101; // Assuming array elements range from 0 to 100
    int hash[MAX] = {0}; // Fixed-size array as a hash table

    // Traverse the input array and populate hash
    for (int i = 0; i < n; i++) {
        hash[arr[i]]++;
    }

    // Print elements with count > 1
    cout << "Repeated elements are: ";
    for (int i = 0; i < MAX; i++) {
        if (hash[i] > 1) {
            cout << i << " ";
        }
    }
    cout << endl;
}

int main() {
    int arr[] = {1, 2, 3, 4, 2, 5, 3, 6, 4};
    int n = sizeof(arr) / sizeof(arr[0]);
    findRepeatedElements(arr, n);
    return 0;
}
